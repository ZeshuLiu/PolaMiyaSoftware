# 吐片页：上方出片、底部计时

仅渲染提案，未修改现用 EJECT 设计、固件或资源导出器。

- 上方：42×50 px 相纸旋转 180°，白色宽边朝上，由出片口向上移出。出片口为 (43,94)、70×6 px，纸张顶边由 y=94 移至 y=40；可见窗口 y=34–94，纸张在口内的部分裁切隐藏。
- 中间：保留电流读数、0–1.5 A 圆环与单位，圆环中心由 y=165 下移至 y=173，为出片口和刻度留出间隔。
- 底部：EJECT TIME 标签基线 y=267，Space Mono Bold 28 px 计时基线 y=302。
- 沿用黑色顶栏、绿色主体、电池及右侧停止图标。动画循环 2.6 s，先向上移出，稍停后淡出；动画是运行示意，不代表实际纸张位置。

`preview.png` 为出片初段、半程和完全露出三种状态；`eject-up.gif` 为循环动画。字体取现行 SVG 内嵌的 Space Mono / Roboto Mono。所有读数均为示例。

先运行 `create_preview.cjs <node_modules路径> <chrome.exe路径>`，再运行 `create_animation.py` 组装 GIF。只渲染并查看静态图和动画帧，未编译、测试、运行固件或烧录。
