# HOME / INFO 第三版：明亮配色与远距离辨认

2026-10-29。用户确认屏幕对角线只有 1.47 英寸，观看距离为手持较远；喜欢第一版配色与第二版布局。本版保留两版原文件，仅新增设计预览。

## 设计

- 保留第二版的双距离卡、右侧操作栏、即时标尺和底部相纸余量；UPTIME 留在 INFO 首项。
- 对焦卡恢复明亮鲜绿 `#79f5a7`，深色文字 `#09291e`；实测为亮蓝 `#69d6ff` 配深蓝底 `#072b42`。侧栏浅薄荷 `#d4ffe7`，当前功能深绿底。编辑态使用亮橙 `#ffbe58`。
- 两组距离均增至 Space Mono Bold 50 px；小数点步距 12.5 px，数字步距 30 px，单位 Roboto Mono Bold 15 px。FOCUS / ACTUAL 为 14 px、700 字重。
- 侧栏主图标由第二版 16 px 增至 22 px，上下箭头/加减号使用 3 px 笔画。当前功能文字为 9.5 px 粗体，只作图标的辅助说明。
- 删除 MENU / EDIT 顶栏小字、相邻功能小字和分页点。相邻功能仍保留较大图标；编辑步长 50 mm 使用 10 px 粗体。
- 标尺沿用对数映射，标签简化为 0、5、20、独立无穷远图形；指针放大为 8×7 px。无穷远图形仅替代标尺上的 INF，距离读数的 INF / NEAR / 无效状态规则不变。
- FILM 标签 13 px、余量数字 24 px。亮暗相纸对比增强，保留八格。
- INFO 标签增至 12–13 px，正文 14 px，UPTIME 数字 20 px；其他信息项保留。
- 卡片圆角 4 px、按键圆角 3 px；实体键中心 y=54/160/266 不变。
