## 四类菜单项

| 类型 | 显示方式 | 中键短按 | 上下键 | 持久化 |
| --- | --- | --- | --- | --- |
| 数值 | 名称＋大号数值 / 单位；有明确范围时显示短进度条 | 进入编辑，再按完成编辑 | 浏览时选项目，编辑时增减数值 | 沿用长按中键保存；未保存时显示 UNSAVED |
| 执行 | 名称＋动作词 START＋右箭头 | 启动动作；执行中显示 RUNNING 和禁用的中键提示 | 浏览和切换项目 | 动作按自身流程保存，寻零仍在完成后自动保存 |
| 少量选项 | 名称＋当前值，ON/OFF 使用分段选项 | 进入编辑，再按确认选项 | 浏览时选项目，编辑时切换前后选项 | 与数值项采用一致的保存规则 |
| 多选项单选 | 主菜单显示名称＋当前值＋进入箭头，进入后为独立选项列表 | 进入列表；确认候选值后返回父菜单 | 列表中逐项移动，超出屏幕自动滚动 | 确认更新 RAM、标记 UNSAVED，仍由父菜单长按中键保存 |

BACK 独立为导航项，以左箭头与文字表示，短按中键返回。执行中的动作不能被 BACK 当作取消；是否可中止仍由实际设备协议决定。

## 多选项子菜单

- `submenu-preview.png` 展示入口 → 浏览候选项 → 确认返回。主菜单在 LANGUAGE 项第二行显示当前 ENGLISH，右侧空心箭头表示进入，区分动作项的播放符号。
- 子页面以选项名称作标题，右上角显示候选项序号 / 总数；标题下方始终显示当前值及勾号，即使当前项已滚出列表也能辨认。
- 橙色背景只表示正在浏览的候选项，勾号才表示当前值。上下移动不立即改值；中键确认后才更新父菜单中的当前值，并显示 UNSAVED。
- 示例 8 个选项，每屏 5 行，右侧细滚动条表示当前可见范围；不将所有选项挤在一行，也不缩小字号。更长的选项名称可用两行并调整可见行数。
- BACK 固定在列表底部，导航到该项后按中键，保留原值返回。确认当前值也允许直接返回，不应增加无意义的待保存变化。
- 此处仍为单选列表，不能将“多选项”误作可以同时勾选多个值。

## 视觉规则

- 绿色实底表示选中项目；橙色表示正在编辑；蓝色描边与 RUNNING 表示动作执行中。
- 普通卡片使用深绿底、细边框和高对比文字，不在屏内额外写 VALUE / ACTION 等类型标签。
- 项目名称和提示 14 px，页面标题 16 px，数值 24 px；不通过缩小字体解决空间问题。
- 数值区和选项区放在卡片第二行，长名称不会与值挤在同一行。动作箭头位于右侧。
- 侧栏继续对应上 KEY3、中 KEY2、下 KEY1。数值编辑使用加 / 减，选项编辑使用上 / 下，完成用勾号；执行项中键用播放符号，执行中用灰色省略号。
- 现有三项菜单显示背光、寻零和返回；未来增加选项时采用四项紧凑布局。项目继续增加时应滚动列表，并保持字号，不无限压缩卡片。
- 底部提示根据选中项目变化：数值显示保存状态及保存入口，执行显示设备状态和执行入口，选项显示确认入口。
