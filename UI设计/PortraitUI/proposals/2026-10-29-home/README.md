# HOME 新布局提案

2026-10-29。仅设计预览，未接入固件。图中数值为示例。

- 保持 172×320、三实体键交互和现有功能：对焦/实测距离、即时对数标尺、相纸余量、电池及运行时间。
- 侧栏改为 x=136、宽 36 px 的浅薄荷色独立区域。当前功能用深色块、图标和文字标识；上下显示相邻功能。完整功能顺序仍为 SETTINGS → FOCUS → EJECT → INFO。
- 按键图标中心保持 y=54/160/266。浏览状态为上一个/进入/下一个；对焦编辑为增加/完成/减少，步长沿用 50 mm。
- 对焦为绿色读数卡，实测为深蓝底读数卡。编辑时对焦卡和确认键同时改为橙色。
- 使用仓库固定的 Space Mono Bold 和 Roboto Mono 字体文件；距离分别为 44/40 px，小数点步距为字号的 0.25 倍、数字为 0.60 倍，保留紧凑的小数点排版。
- 窄屏标尺保留 0–20 m 对数映射及独立 INF，仅显示 0/1/5/20 标签。相纸显示八格，六格点亮为示例。

`preview.png` 为浏览/对焦编辑两种状态的展示图；两个 `*-4x.png` 为单屏四倍预览；SVG 内嵌字体，可独立打开。`preview.html` 为展示图源，`create_preview.cjs` 用本地 Playwright 渲染。
