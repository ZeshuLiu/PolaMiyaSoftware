# HOME / INFO 第二版预览

2026-10-29。按用户反馈修改设计，保留第一版，未接入固件。图中数据均为示例。

- HOME 移除 UP，运行时间作为 INFO 第一项 UPTIME；INFO 保留电池、电机/IPROPI、重启/快门次数、电机累计时间和 EEPROM 状态。
- 底色保持近黑，读数卡改用低饱和深绿/深蓝；绿色表示对焦、蓝色表示实测，橙色表示正在编辑。
- 36 px 侧栏改为中等亮度的灰绿底，当前功能用浅绿块突出；编辑时当前功能块变为琥珀色。上下按键使用较浅灰绿底。
- 读数卡圆角 4 px，按键圆角 3 px。屏幕外缘的 17 px 圆角仅为预览裁切，实际外缘遵循屏幕形状。
- HOME 底部只保留相纸数量与八张相纸示意。三键中心保持 y=54/160/266。
- 沿用仓库中的 Space Mono Bold / Roboto Mono；数值字号和小数点间距沿用第一版。

`preview.png` 展示 HOME 浏览、FOCUS 编辑和 INFO。三个 SVG 内嵌字体，三个 `*-4x.png` 为单屏四倍预览。`create_preview.cjs` 通过本地 Playwright 生成图片和展示页。
