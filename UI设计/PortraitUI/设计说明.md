## 显示基础

- 逻辑画布 172×320，RGB565。沿用已确认的 CASE 7：LVGL ROT 180、面板 gap=(34,0)。GUI Guider 按正常朝上的 172×320 画布设计，不在编辑器中倒置控件。
- 四角保守留白，主要内容左右留 16 px。真实圆角范围仍以屏幕观察为准。
- 黑底、白字；绿色对应对焦距离和上指针，蓝色对应实测距离和下指针。异常同时显示文字，不只改变颜色。
- 界面文字先使用英文，延续旧版；双距离七段数字高 24 px，正文沿用当前默认字体。两项距离均以 m 显示，顺序为对焦/实际；中英文切换另行设计字库。
- `portrait-ui.svg` 为三页布局示意，数字均为设计样例，不代表实测。

UI 每 50 ms 读取实测快照并调用 `focus_distance_get()`。对焦来源尚未接入，暂用同一实测快照，内部以 using_actual 标记占位来源，屏幕不显示状态行，预留有限/无穷远/不可用三种状态。比例尺公式为 `x=14+98×ln(1+d/1m)/ln(21)`，零点可表示；20～49.999 m 的有效读数只将指针限在 20 m，数值不截断。合法返回值 <50 mm 显示 NEAR、下指针停零端；≥50000 mm 的 NO_TARGET 按用户约定显示 INF、下指针移到 INF，当前对焦占位值同步显示 INF。实测太近时对焦占位值不可用，但 FocusUnit 接口本身不增加 NEAR 状态。过期与通信异常仍显示短横线并隐藏对应指针。50000 协议值无法区分太远、太近或无有效反射，INF 是显示约定。

实测曲线按 100 ms 网格保留 101 点，覆盖 10 s；串口继续每 1 s 输出，与 UI 刷新周期独立。无效样本写为 `LV_CHART_POINT_NONE`，不补零、不沿用旧值。曲线纵轴含单位并适当留余量；丢失周期保留断点，不压缩历史时间轴。

## 信息与设置页

信息页：ADC 电池电压、估算电量、电机电流与 IPROPI 电压、重启次数、快门次数、电机累计时间、EEPROM 状态。原温度预留行用于电机 ADC；原始数据未校准时显示 ADC RAW，饱和显示 ADC SAT，过期或失败使用短横线；计数显示存储字段实际值，不补做启动计数或运动累计逻辑。电池图标按估算值填充，失效时显示问号。

设置页：提供背光、保存、返回。背光调节先作用于 RAM 和 PWM，确认保存时才调用 `settings_commit()`；保存失败显示失败并保留未保存标记，不显示成功。百分比接口与 300 ms 开启渐亮已接入。对焦校准、自动/手动模式尚无业务实现，本版不放可操作入口。

用户确认目前只有 KEY1–KEY3 可用。KEY1/3 左右切页；SETUP 页短按 KEY2 切换编辑状态，编辑时 KEY1 减、KEY3 加亮度；SETUP 长按 KEY2 保存。KEY4–KEY6 不分配功能，不依赖触摸。原 SVG 的 SAVE / BACK 为前版示意，当前以右侧图标表达功能；SETUP 长按 KEY2 保存。

## GUI Guider 可行性与接入

现有工程为 GUI Guider 1.10.1-GA、Simulator 模板、LVGL 9.3.0，与固件固定的 LVGL 9.3.0 一致。上述 Screen、Label、Line、Bar、Chart、Button 均可用常规 LVGL 控件完成；距离取样、动态刻度、曲线范围、按键映射和 EEPROM 保存由手写业务代码处理。Simulator 导出是界面源代码来源，不能把其桌面入口、显示驱动或 LVGL 副本直接加入 ESP-IDF。

实施时保留 `MainControl` 原工程，在独立 `PortraitUI` 工程中创建 172×320 画布；生成控件代码与手写 `ui.c / ui_binding.c` 分开，避免再次生成时覆盖业务逻辑。`generated/` 负责建对象，业务层只更新对象和响应事件，驱动不操作 UI。

固件建议新增 `main/app/ui/`，CMake 注册生成源文件及字体。`display_init()` 后用 `ui_start()` 替换 `lcd_test_start()`；方向 7、gap、清屏及背光初始化应从测试模块移交正式显示初始化，恢复官方默认刷新定时器，不保留测试的手动全屏刷新循环。通过 LVGL 定时器更新对象；其它任务调用 LVGL 时使用 `lvgl_port_lock/unlock`。

技术上可行，但 GUI Guider 的工具/生成代码授权需覆盖目标芯片：NXP 产品页描述免费使用范围为 NXP MCU，当前生成文件标有 NXP Proprietary，不能仅因输出 LVGL 代码就认定 ESP32 部署授权已经满足。若现有许可未覆盖 ESP32，按此布局直接手写 LVGL 9.3 控件也能实现。
