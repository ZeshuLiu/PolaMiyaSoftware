# 对焦标定拟合

输入文件 `cal` 后的 12 位十六进制 MAC 地址作为设备序列号，例如 `cal90DA724F2FBC.csv`；同一设备的不同文件可在 MAC 后加下划线和日期等后缀。详细结果输出到 `Result/序列号/`，每个输入文件的简明公式输出到 `Result/Formula/`。同名输入重新运行会覆盖对应结果。

完整拟合三个参数：

```powershell
python fit_focus.py cal90DA724F2FBC.csv
```

固定参考模型的距离项，只拟合新设备整体偏差：

```powershell
python fit_focus.py cal新设备MAC.csv --reference-model Result/90DA724F2FBC/cal90DA724F2FBC_model.json
```

模型为 `RAW(d) = 整体偏差 + A/(d-B)`，距离 `d` 单位为米。参考模型提供固定的 A、B；新设备的整体偏差是各测量点 `RAW - A/(d-B)` 的等权平均，无穷远点的距离项为零。此模式至少需要一个有限距离点，多个不同距离的点更有利于检查参考曲线是否适合新设备。留一评估重新估计偏差；当没有剩余训练点时不可用。

当前参考曲线只来自一台设备，跨设备能否共用距离项尚未验证。建议用多台设备、多个距离的实测残差评估；超出最远有限实测距离属于外推。拟合残差不等同于实际合焦精度。
