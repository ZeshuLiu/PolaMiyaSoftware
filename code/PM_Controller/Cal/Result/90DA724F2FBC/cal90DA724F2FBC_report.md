# cal90DA724F2FBC 对焦校准拟合

## 曲线

距离 d 的单位为 m，RAW 为编码器位置计数。

```text
RAW(d) = 1016 + (14898.9422517) / (d - (0.25014189161))
d(RAW) = 0.25014189161 + (14898.9422517) / (RAW - (1016))
```

- 无穷远策略：CSV 中无穷远 RAW 的平均值，固定不参与自由优化。
- 模型使用范围：d ≥ 1 m；最远实测有限点 9 m。
- 所有原始点均保留，以 RAW 误差等权最小二乘拟合，不自动剔除大残差点。
- B 是拟合的有效距离偏置，可吸收测距基准与简化模型的影响，不等于独立测出的镜头焦距。

## 方法

采用用户给定的 RAW 与镜头伸出量线性关系。薄透镜方程 1/f = 1/u + 1/v 可得 v-f = f²/(u-f)，因此用带偏置的反比例曲线拟合 RAW。这是物理启发的近似校准模型，不将复合镜头或成像面测距关系当成完美薄透镜。

方程参考：[Edmund Optics: Basic Lens Selection](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/basic-lens-selection/)。

优化先扫描 B，每个 B 下线性求解 A（无 INF 时同时求解 R∞），再做有界一维精细优化。B 约束为 [0, 0.95 × 最近实测距离]，避免校准范围内出现极点。INF 按 1/d=0 处理，不替换成某个人为大距离。

## 输出与使用

```bash
python fit_focus.py cal90DA724F2FBC.csv
```

依赖：numpy、scipy、matplotlib。从任意目录调用脚本均可；参数可以是当前目录路径或 Cal 内的文件名。详细结果输出到 Result/设备序列号，简明公式输出到 Result/Formula；相同输入文件名重新运行会更新对应结果。文件名以 cal 加 12 位 MAC 开头时使用 MAC 作为序列号，其他文件名使用文件名作为文件夹名。

- `*_fit.png` / `*_fit.svg`：曲线、倒距离图及残差图。
- `*_model.json`：全精度参数、公式、源数据 SHA256、数值库版本和误差指标。
- `*_points.csv`：原始行号、实测 / 拟合 RAW、残差及反算距离。反算距离可能超出模型域，由独立标志列标注，不自动裁剪为边界值。
- `*_curve.csv`：均匀倒距离采样的拟合曲线，包含无穷远及整数 RAW。

源 CSV 保持不变。脚本没有修改、构建或烧录主控固件。
