# 字体许可

当前 HOME、INFO、SETUP 界面及其设计资源只使用下列两种项目内字体。

## Roboto Mono

Copyright 2015 The Roboto Mono Project Authors (https://github.com/googlefonts/robotomono)

Roboto Mono 字体及由其转换的位图字形使用 **SIL Open Font License 1.1**。完整许可见 [OFL.txt](main/app/ui/fonts/RobotoMono/OFL.txt)，来源、固定版本和摘要见 [字体说明](main/app/ui/fonts/RobotoMono/README.md)。发布源码或固件包时同时附带该版权声明与完整许可，不单独出售字体。

当前用于正文、小标签、单位、坐标、胶片计数、运行时间与异常状态文字。

## Space Mono

Copyright 2016 The Space Mono Project Authors (https://github.com/googlefonts/spacemono)

Space Mono 字体及由其转换的位图字形使用 **SIL Open Font License 1.1**。完整许可见 [OFL.txt](main/app/ui/fonts/SpaceMono/OFL.txt)，来源、固定版本和摘要见 [字体说明](main/app/ui/fonts/SpaceMono/README.md)。发布源码或固件包时同时附带该版权声明与完整许可，不单独出售字体。

当前使用 Bold 字重，用于品牌标题和大距离数字。

历史归档、旧 GUI Guider 工程及此前的视觉方案保留原状，不是当前固件的字体来源。当前生成流程不使用 Segoe UI、Windows 已安装字体或旧工程的生成字体。
