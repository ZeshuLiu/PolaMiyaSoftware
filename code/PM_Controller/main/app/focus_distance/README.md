# 对焦物距

默认标定参数集中于 `focus_calibration.h`，默认来自设备 MAC `90DA724F2FBC`：`RAW = 1016 + 14898.9422517 / (d - 0.25014189161)`，d 的单位为 m。`focus_distance_to_raw()` 按连续距离计算，不经过手动档位；`focus_distance_from_raw()` 用逆公式生成 FOCUS 显示和绿指针，超出模型范围的 RAW 显示 `--`。无穷远命令目标仍为 RAW 1016。显示反算时，考虑 FocusUnit ±50 RAW 到位容差，RAW 966–1066 均显示为 INF，避免在渐近线附近显示数百米；这只是显示分类，不代表实际光学距离已确认。超出模型域的其它 RAW 仍显示 `--`。

HOME 选中 FOCUS 后，短按 KEY2 读取一次当前有效 SDM50 测距并按公式对焦；长按 KEY2 进入手动模式，手动模式下短按 KEY2 退出。手动模式 KEY3 增大距离、KEY1 减小距离，共 1–10 m 取 17 个对数分布并圆整到 0.1 m 的点，另有 15 m、20 m 和无穷远。当前 RAW 先匹配最接近的档位 RAW，再沿按键方向走一档；两端不循环。移动仍由 focus_position 管理掉电保护及到位保存。

自动对焦读取一次新鲜测距：有限距离小于标定最小距离（默认 1 m，包括 TOO_CLOSE）夹到该最小值，FOCUS 数字及单位红色闪烁；有效距离至少 1 m 时按连续公式计算目标，蓝色显示。`SDM50_NO_TARGET` 按界面原有 INF 约定对焦到无穷远 RAW，蓝色显示；它仅表示测距模块未检测到目标，不是实测无限距离。过期、通信故障或等待中的数据不发起移动。颜色表示目标已受理，不表示已到位；进入手动模式清除自动对焦的颜色状态。手动或自动的距离在 9 m 以上属于有限实测数据外推；当前参数只来自一台设备，其它设备和实机合焦精度尚未验证。

HOME 的 FOCUS 显示目标距离；INFO 的 FOCUS 根据设备当前位置 RAW 反算当前对焦距离，不能当作测距传感器实测距离。初始化未完成或 RAW 超出模型范围时显示 `--`，无穷远显示 `INF`。初始化失败、设备故障、存储错误和通信失效仍显示 I/E/C；恢复与掉电保护见 [focus_position](../focus_position/README.md)。未编译、测试或烧录，实机未验证。
