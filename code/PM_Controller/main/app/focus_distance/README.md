# 对焦目标显示

`focus_distance_get()` 根据 FocusUnit 状态快照返回主机 RAW 目标及显示状态。FOCUS 显示的是用户期望的命令目标，不是当前编码器位置；INFO 显示设备当前 `position`。首次合法状态在用户未编辑且设备目标非负时可作为主机初值，不主动发运动。

用户每按一次增减 1000 RAW，最低 0，最高仅受 int32 协议上限限制。FOCUS 暂以 `RAW / 100000` 显示两位小数，例如 1000 显示 `.01`；保留原 m 字样只是界面占位，尚无物距标定，不能当作真实米数。绿指针暂按 `RAW / 100` 映射到毫米标尺，20 m 端点仅为显示截限，不是运动限位。

设备未初始化、零位无效或最近 MoveRaw 被 BUSY 拒绝显示 I；设备故障、定位堵转或其他协议命令拒绝显示 E；无有效通信、状态过期显示 C。上述状态不显示单位并隐藏绿指针。ACTUAL 仍显示 SDM50 实测及其独立的 INF / NEAR / 失效状态。串口和 ACK 边界见 [FocusUnit 主机](../../drivers/focus_unit/README.md)。未编译、测试或烧录，实机及校准未验证。
