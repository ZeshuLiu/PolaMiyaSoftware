# BLE 遥测和手动对焦

在相机 `SETTINGS → NETWORK → BLE REMOTE` 短按 KEY2 开启或关闭，手机小程序连接 `POLA_XXXXXX`。首次系统配对时输入相机显示的六位 PIN，后续用 BLE Secure Connections 的绑定密钥恢复已认证连接。小程序只记录最近确认绑定的设备 ID，在前台打开或该设备意外断开时尝试重连。主动断开或打开演示时，本次页面会话暂停自动重连。

遥控开关存入 EEPROM 的 ID 14，旧记录默认关闭。开机在 Wi-Fi 恢复流程结束后恢复遥控，开启时保持广播，连接断开后恢复广播，直到用户关闭。保存失败显示 `SAVE ERROR`，可在设置页长按 KEY2 重试。与 `PAIR WIFI` 互斥，先停止当前模式再开启另一项。

本机已启用 `CONFIG_BT_NIMBLE_NVS_PERSIST=y`。手机的 BLE 绑定密钥存入 NVS，可在关闭遥控或重启后恢复认证。

PIN 错误或配对超过 35 秒时，后台任务释放失败的连接并恢复广播，菜单保留 `PAIR FAILED` 提示。串口记录认证返回码和断线原因。用户报告的卡死尚无现场日志，恢复改动未在板上验证。

小程序显示 SDM50 实测距离，以及由当前镜头标定反算的实际对焦距离和设定目标。手动输入接受当前标定最短距离至 20 m，或选择无穷远。相机 UI 任务使用同一标定和 `focus_position_set_target()`，保留运动前 EEPROM 失效、到位停机和保存流程。未寻零、通信或存储异常、本机正在手动编辑、对焦运动或吐片时不接受新目标。命令回执表示受理，镜头实际距离单独回报。

## GATT v2

以下短号替换 `7E40000N-B5A3-F393-E0A9-E50E24DCCA9E` 的 `N`。

| 短号 | 用途 | 字节序与字段 |
| --- | --- | --- |
| 1 | 主服务 | 广播名 `POLA_` 加蓝牙 MAC 末六位 |
| 2 | Read / Notify | 17 字节，小端。版本 u8、标志 u8、测距 mm u16、实际对焦 mm u32、目标对焦 mm u32、最短对焦 mm u16、回执序号 u16、结果 u8 |
| 3 | Write with response | 7 字节，小端。版本 u8、非零命令序号 u16、目标 mm u32（0 表示无穷远） |

状态标志 bit 0 测距有效、bit 1 无目标、bit 2 实际对焦有效、bit 3 实际对焦为无穷远、bit 4 目标有效、bit 5 目标为无穷远、bit 6 已认证且可提交对焦、bit 7 当前连接已认证且已绑定。结果 0 无回执、1 已受理、2 距离超出范围、3 本机忙、4 对焦未就绪。连接断开时清除待处理命令和回执；已交给对焦状态机的目标继续处理。认证后通知间隔约 250 ms。

固件仅静态核对，未编译、烧录或实机验证。
