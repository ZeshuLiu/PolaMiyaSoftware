# 开机画面

2026-10-19。屏幕与 LVGL 就绪后立即显示狗图、逐行初始化状态及出厂 MAC，外设初始化结束后进入现有三页 UI。

## 画面

- 黑底，Space Mono 白色标题及矩形五色标记。
- 狗图使用 `assets/dog/dog.png`：显示区域裁切到原图 (29,13,165,72)，置于 (28,48) 的 116×64 px、圆角 14 px 白色矩形内，比上一版上移 34 px。原始 PNG 保持不变。
- 狗图下方 x=23、基线 y=137 显示 `SYSTEM STARTUP`；完成后变为 `SYSTEM READY`，存在可继续的错误时为 `READY / WARN`。前方为小方点，日志与 MAC 区域以两条淡线分隔。
- 六行日志位于 x=14、y=156 起，每行间隔 20 px，基线依次为 y=167/187/207/227/247/267。左侧模块名，中间 `....`，右侧状态标记对齐到 x=158。初始化中的行显示 `[...]`，成功显示绿色 `[OK]`，失败显示橙色 `[FAIL]`；已完成的行保留，尚未开始的行留空。
- 底部居中显示 `MAC : AA:BB:CC:DD:EE:FF`，基线 y=307。通过 `esp_efuse_mac_get_default()` 读取 6 字节出厂基础 MAC，使用大写十六进制与冒号，不初始化 Wi-Fi、不设置 MAC、不写 eFuse。读取失败显示 `MAC : --` 并保留警告标记。
- 开机背景、白色圆角卡片、小方点和分隔线由 LVGL 原生对象绘制，不保存整屏位图。`boot.svg` 仅导出 78×17 px RGB565 标题（2652 字节）及 100×48 px A8 狗图蒙版（4800 字节）。A8 保留灰度抗锯齿，以黑色直接混合到白卡片上，无需 PNG 解码或新增图像解码器。
- 启动日志和状态标记使用 Roboto Mono 9 px、Medium 字重，LVGL 字间距 1 px；小标题和 MAC 使用 Roboto Mono 8 px，品牌标题使用 Space Mono Bold。两个启动字号仅导出当前固定文字需要的字符，日志含大写字母、空格、点和方括号，小标题及 MAC 另含数字、冒号、斜线和连字符。新增启动文字时同步扩充导出脚本的字符集；不在设备上加载 TTF。

## 资源占用

与整屏位图版相比，图像像素由 110080 字节降至 7452 字节；启动字形像素由 5865 字节降至 2338 字节，两项合计减少 106155 字节（约 103.7 KiB），另减少字形描述和字符索引。布局、配色、狗图裁切和启动流程保持。此处为生成资源的静态统计，最终固件净变化包含新增绘制代码与链接对齐，以手动编译结果为准。

## 启动阶段

| 初始化阶段 | 屏幕模块名 |
| --- | --- |
| 屏幕 / LVGL / 开机画面 | DISPLAY SYS |
| 闪光定时器与快门输入 | TRIGGER SYS |
| KEY 输入 | KEY INPUT |
| SDM50 初始化与开启 | RANGE SENSOR |
| 参数存储加载 | PARAM STORE |
| ADC 初始化 | ADC INPUT |

`boot_screen_begin()` 在进入驱动前追加该阶段的状态行；`boot_screen_complete()` 在返回后更新本行结果，不覆盖此前结果。`[OK]` 表示初始化接口成功返回，不代表传感器数据已有效或硬件已完成验收。测距、存储或 ADC 失败时保留本行 `[FAIL]` 并继续；最终标题显示 `READY / WARN`。原有致命初始化错误仍按原来的 `ESP_ERROR_CHECK` 停止或复位。MAC 读取失败显示 `MAC : --`，并使最终标题保留警告。

GPIO38 在屏幕初始化之前先通过 `flash_trigger_prepare_output()` 配置为低电平；GPTimer 和快门 ISR 在开机画面显示后再启用。

## 锁与生命周期

仅启动任务调用本模块。所有 LVGL 对象操作持有 `lvgl_port_lock()`；阶段更新主动请求刷新，然后释放锁，再进入外设调用。EEPROM、串口等待等驱动初始化不持有显示锁；官方移植层继续拥有刷新任务和 SPI/DMA 回调。

开机画面使用背光驱动的默认启动亮度，并调用原有非阻塞渐亮。`boot_screen_finish()` 是最后一次开机画面调用；随后 `ui_start()` 应用存储的亮度，`ui_view_create()` 清理同一活动屏上的开机对象并建立 HOME，重复的背光开启请求不重启渐亮。若存储亮度为 0，进入主界面时按原约定熄灭背光。
