# EEPROM 参数管理

启动时由 `settings_init()` 初始化 24C64 并加载最新完整记录。无记录时使用 RAM 默认值；器件不可用或读取失败时返回错误、保留 RAM 默认值并禁止提交。启动不写入、不导入旧数据、不递增统计量。应用层更新参数后，在业务完成或用户确认保存时调用 `settings_commit()`。

## 与旧版实现的区别

| 项目 | Rev1 实现 | 当前实现 |
| --- | --- | --- |
| 器件访问 | STM32 HAL；单字节地址加从地址块位；逐页写后等待被注释 | ESP-IDF 官方 I²C；24C64 双字节地址；分页及 ACK 轮询 |
| 参数布局 | packed 结构体与手写字节偏移 | 稳定参数 ID、长度和值；明确的小端编码 |
| 数据校验 | 版本字节，无 CRC | 版本、长度、序号、CRC32 和提交标记 |
| 中断写入 | 原地址覆盖 | 31 个记录轮换；写新记录、回读验证，再写提交标记 |
| 写入频率 | 每次更新立即写；部分初始化也写相同值 | RAM 更新与提交分开；相同值或改后恢复原值不重复写 |
| 模块关系 | 存储函数直接更新 UI 字符数组 | 器件、参数与 UI 分开，外部通过接口访问 |
| 计数容量 | 32 位计数 / 电机运行量 | 64 位计数和毫秒累计；拒绝溢出 |

旧版来源：[eeprom.c](../../../../../archive/PM_Controller_Rev1_x/MainController/Libs/EEPROM/eeprom.c)、[DataStore.c](../../../../../archive/PM_Controller_Rev1_x/MainController/Libs/EEPROM/DataStore.c)、[DataStore.h](../../../../../archive/PM_Controller_Rev1_x/MainController/Libs/EEPROM/DataStore.h)。

## 参数定义

| 稳定 ID | 接口键 | RAM 字段 | 默认值 | 范围 / 单位 |
| --- | --- | --- | --- | --- |
| 1 | `SETTINGS_REBOOT_COUNT` | `reboot_count` | 0 | uint64，次数 |
| 2 | `SETTINGS_SHUTTER_COUNT` | `shutter_count` | 0 | uint64，次数 |
| 3 | `SETTINGS_MOTOR_RUN_MS` | `motor_run_ms` | 0 | uint64，毫秒 |
| 4 | `SETTINGS_BACKLIGHT_PERCENT` | `backlight_percent` | 100 | 0–100，百分比 |

计数和参数均使用无符号 64 位 RAM 字段及持久化值。背光百分比目前只存储，尚未应用到 PWM；校准字段尚未定义。

新增参数时，在 `settings.h` 增加不重复的稳定 ID 和 RAM 字段，在 `settings_record.c` 的 `parameters[]` 增加字段、默认值、最大值和是否为计数器。编码、校验、赋值和默认值都复用这张表，无需维护 EEPROM 字节偏移。当前记录可容纳最多 17 个 8 字节参数，超过限制会触发编译检查。

已有 ID 和单位不改、不复用。兼容新增字段时保留记录版本，旧记录缺少的字段采用默认值；固件遇到未知字段或未知记录版本时返回 `ESP_ERR_NOT_SUPPORTED` 并禁止提交，避免降级丢失新参数。停用字段应保留解析项；改变含义、单位或编码类型时增加新 ID 或明确迁移版本。

## 保存格式与恢复

| 区域 / 字段 | 地址 / 大小 | 内容 |
| --- | --- | --- |
| 预留区域 | `0x0000–0x00FF` | 保留旧数据；Rev1 v2 位于 `0x20`，共 13 字节 |
| 轮换记录 | `0x0100–0x1FFF` | 31 个记录，每个 256 字节 |
| 记录头 | 记录内 `0–15` | `PMPS`、u16 版本、u16 载荷长度、u32 序号、u32 CRC |
| 参数载荷 | 记录内 `16–223` | 每项为 u16 ID、u16 长度、8 字节值；均为小端 |
| 提交标记 | 记录内 `224–227` | `SAVE`，独占最后一个 32 字节物理页 |
| 剩余提交页 | 记录内 `228–255` | 预留 |

CRC32 使用标准 IEEE 多项式，覆盖头部前 12 字节和有效载荷。加载时校验提交标记、长度和 CRC，再解码参数，选择最新有效序号；序号支持 uint32 回绕。最新记录损坏时回退上一条完整记录。若扫描中出现 I²C 读取错误，则停止加载并禁止提交，避免依据不完整扫描覆盖数据。

提交过程：使目标标记失效并回读确认 → 写入头部与载荷并回读确认 → 写入提交标记并回读确认。上一条最新记录始终保留。任一步失败都返回错误，RAM 保持待保存状态，可以重试。通信失败时设备是否已完成最后一次写入可能不确定，重启加载以实际有效记录为准。

轮换分散写入位置，但仍应合并高频变化。电机运行量可在运行期间只累计 RAM，在一次动作完成时提交；确认保存和关机前保存均由业务层安排。提交失败后重试 `settings_commit()`，不重复执行增量更新。不要从扫描任务或 ISR 直接频繁提交。

## 外部接口

| 接口 | 内容 |
| --- | --- |
| `settings_get(&values)` | 读取 RAM 参数快照 |
| `settings_get_status(&status)` | 读取 dirty、加载来源、是否可写、序号及最近存储错误 |
| `settings_set(key, value)` | 校验并更新一个 RAM 参数 |
| `settings_increment(key, amount)` | 原子累计统计量；背光等非计数参数不能使用 |
| `settings_commit()` | 有变化时同步提交；成功后清除 dirty |
| `settings_import_rev1()` | 显式读取当前 EEPROM `0x20` 的旧版 v2 内容，仅更新 RAM |

所有接口使用任务互斥锁。参数服务先持有参数锁再调用器件驱动，不在持锁期间调用 UI 或外部回调。初始化完成后再启动参数消费者。初始化失败后可读取和修改 RAM 默认值，提交返回存储错误；启动时器件不可用的情形需重启后重新初始化。

```c
#include "settings.h"

/* settings_init() 已在 app_main() 调用。 */
esp_err_t result = settings_set(SETTINGS_BACKLIGHT_PERCENT, 60);
if (result == ESP_OK) {
    result = settings_commit();
}
/* 调用者检查 result，再决定是否显示保存成功。 */

settings_values_t values;
result = settings_get(&values);
```

显式导入只支持旧版 v2 的 13 字节布局：版本字节和三个小端 uint32 值。适用于旧记录已复制到当前 24C64 的情形；导入后仍需调用 `settings_commit()`，原字节不修改。已有新格式记录时拒绝导入；旧格式没有 CRC，数据正确性需自行确认。
