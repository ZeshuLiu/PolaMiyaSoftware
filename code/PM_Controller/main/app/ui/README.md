# 竖屏 UI

2026-10-17：直接使用 LVGL 9.3 C API 实现，不包含 GUI Guider、SquareLine 或 EEZ 的新工程文件。参考布局和旧版 GUI Guider 工程保存在仓库根目录 `UI设计/`。新代码不引用旧工程的生成源文件、字体或桌面模拟器。

## 页面

- HOME：`对焦距离 / 实测距离`（m），0–20 m 对数比例尺及无穷远端点、上下双指针、最近 10 秒实测距离曲线、本次开机时间。绿色左值及上指针对应对焦距离，蓝色右值及下指针对应实测距离。数字为 LVGL 矩形组成的七段数码字，不依赖额外字体或 sdkconfig 修改。
- INFO：ADC 电池电压与估算电量、电机电流与 IPROPI 电压、重启次数、快门次数、电机累计时间、参数存储状态。计数直接显示 settings 字段，大数单行滚动；不在界面中补做业务计数。原温度预留行用于电机读数，温度驱动尚未接入。
- SETUP：背光百分比、编辑状态和保存结果。每次短按调节 5%，范围 0–100%；0% 会熄灭背光，KEY1–3 仍可操作，编辑状态按 KEY3 可恢复亮度。返回主页不撤销 RAM 修改。长按 KEY2 显式写 EEPROM；保存失败显示 `SAVE FAILED`，参数服务保留未保存状态。

主屏右上角为 LVGL 对象绘制的电池图标，不显示 BAT 文字。ADC1 采用最低连续 DMA 总采样率 611 Hz，两路约各 305.5 Hz，每路 31 个样本生成约 100 ms 一组快照；`power_monitor_get()` 按单节 4.2 V 锂电池电压估算电量。`ui_view_battery(-1)` 显示未知 `?`，传入 0–100 时按百分比填充；无校准、饱和、初始化失败或过期均恢复未知。该内部绘制接口须持有 LVGL 锁。采样与估算见 [adc_measure](../../drivers/adc_measure/README.md) 和 [power_monitor](../power_monitor/README.md)。

## 目前只使用 KEY1–KEY3

用户确认右侧实体键从上到下为 **KEY3、KEY2、KEY1**。后续固定沿用 **KEY3=上/右/增加、KEY1=下/左/减少、KEY2=确认/执行**。对应图标中心暂设 y=84/160/236，待实物测量后只调整 `ui_key_hints.c` 的位置表，不改变输入位与 KEY 编号关系。

右侧仅保留 16 px 图标区，背景在最后 24 px 横向渐入、上下各 160 px 渐隐，无贯穿分隔线。图标通过 LVGL Line 和圆形边框绘制，不使用中文或额外字体；图标提亮以增加辨识度，背景继续弱化。切页时上键 KEY3 显示右箭头、下键 KEY1 显示左箭头；编辑时两者显示加、减；中键 KEY2 按页面显示齿轮/调节/完成，SETUP 页长按中键保存。后续纵向菜单采用上下箭头，语义保持 KEY3 上、KEY1 下。顶部区域 30 px，电池主体 19×10 px，主体内容右缘约 x=144。

当前预览见仓库根目录 `UI设计/PortraitUI/key-icons-v4-preview.png`。这是设计示意，不是固件截图；字体、边缘渐变及实际按键高度仍待上板确认。v3 为旧按键映射参考。

| 输入 | 浏览页面时 | SETUP 编辑亮度时 |
| --- | --- | --- |
| KEY3 短按（上键） | 向右切下一页，三页循环 | 增加 5% |
| KEY2 短按（中键） | HOME/INFO 确认进入 SETUP；SETUP 进入编辑 | 确认完成编辑，停留 SETUP |
| KEY1 短按（下键） | 向左切上一页，三页循环 | 减少 5% |

| KEY1/3 长按 | 无操作 | 无操作 |

KEY4–KEY6 尚未接线，不分配功能。UI 是 `hc165_take_events()` 的唯一消费者；每次会清除驱动全部事件，今后增加其它按键业务时应在此处统一分发，不能再增加互相抢事件的消费者。闪光触点 GPIO42 的原有 ISR 路径不变。

## 文件和调度

### 按键功能入口

调用链：`hc165.c:scan_inputs()` → `hc165_keys_update()` 识别并累计事件 → `ui.c:ui_task()` 每 50 ms 调用 `hc165_take_events()` → `handle_keys()` 执行具体功能。

修改按键业务从 `ui.c` 的 `handle_keys()` 入手：KEY1/3 修改页号或调用 `settings_set()` 和 `lcd_st7789_set_brightness()`；KEY2 短按进入/完成编辑，长按调用 `settings_commit()`。`ui_key_hints.c` 只显示当前按键功能，不处理输入事件，也不执行保存。后续扩展仍由这一处统一消费并分发事件。

`app/focus_distance/focus_distance_get()` 是独立的对焦物距获取接口。FocusUnit 目前只有编码器计数，主控通信和“位置计数 → 物距”的标定尚未接入，因此该函数暂用本次 SDM50 快照，并设置 `using_actual=true`，占位标志仅保留在接口返回值中，屏幕不显示状态行。实测有效时两项数值和两个指针对齐；NO_TARGET 按用户约定将两项显示为 INF、两个指针指向 INF。实测太近时右值 NEAR、下指针停在零端点；对焦接口不增加 NEAR 状态，左侧占位值暂不可用、上指针隐藏。后续接入真实 FocusUnit 后，左值与上指针独立于实测 NEAR 状态。

比例尺刻度为 0、1、2、5、10、20 m 和 `INF`（无穷远）。为包含零点，有限距离采用 `x = 14 + 98 × ln(1 + d/1m) / ln(21)`；20 m 位于 x=112，INF 独立位于 x=139，中间断线分隔。20～49.999 m 仍显示真实数值、指针停在 20 m；合法返回值 <50 mm 显示 NEAR，≥50000 mm 的 NO_TARGET 显示 INF。50000 是“测不到”协议值，显示 INF 是约定，不代表确实测得无穷远，也无法排除太近或反射不足。等待、过期、停止或接收错误显示短横线、隐藏对应指针，不沿用 INF。

`ui_view.c` 只创建与更新 LVGL 控件；`ui.c` 负责快照、按键和参数保存。独立优先级 3、4096 字节栈任务，每轮处理事件和快照后阻塞 50 ms，不补跑过期周期，操作 LVGL 时持有官方移植锁。只更新当前页控件；数码段、透明度及编辑颜色按变化更新，电池和页面重复值跳过，避免相同样式也触发重绘。EEPROM 保存前释放显示锁；保存期间 UI 任务暂停取样，LVGL 官方任务仍可刷新。

曲线按单调时钟 100 ms 网格保存 101 点。调度延迟或 EEPROM 保存跨过的网格填空缺，不将同一个样本复制填满历史；只将 VALID 快照写入最新点。NEAR、INF、过期、停止和接收错误在曲线中均为 `LV_CHART_POINT_NONE`，不画成 0 m 或 50 m。横轴 10 s，纵轴单位 m、整数米边界；原始数据保留 mm。大字按米四舍五入至两位小数，显示位数不代表传感器精度。

`display_init()` 负责 CASE 7、完整 RAM 清屏和可见窗口偏移；`ui_start()` 建界面并开启约 300 ms 的背光渐亮。日常刷新由官方 LVGL 定时器管理，不调用屏幕测试的全屏刷新循环。`lcd_test` 源码仍保留，需要排查屏幕时可手动切换启动入口，两者不能同时运行。

主程序每 1 s 打印距离及 ADC/电源快照。只改软件源码及文档，未修改 sdkconfig，未测试、未编译、未烧录，实机未验证。
