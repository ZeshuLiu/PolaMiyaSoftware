## 页面

- HOME：`对焦距离 / 实测距离`（m），0–20 m 对数比例尺及无穷远端点、上下双指针、最近 10 秒实测距离曲线、本次开机时间。绿色左值及上指针对应对焦距离，蓝色右值及下指针对应实测距离。标题和大数字使用 Space Mono，小字使用 Roboto Mono。
- INFO：ADC 电池电压与估算电量、电机电流与 IPROPI 电压、重启次数、快门次数、电机累计时间、参数存储状态。计数直接显示 settings 字段，大数单行滚动；不在界面中补做业务计数。原温度预留行用于电机读数，温度驱动尚未接入。
- SETUP：背光百分比、编辑状态和保存结果。每次短按调节 5%，范围 0–100%；0% 会熄灭背光，KEY1–3 仍可操作，编辑状态按 KEY3 可恢复亮度。返回主页不撤销 RAM 修改。长按 KEY2 显式写 EEPROM；保存失败显示 `SAVE FAILED`，参数服务保留未保存状态。

主屏右上角为 LVGL 对象绘制的电池图标，不显示 BAT 文字。ADC1 采用最低连续 DMA 总采样率 611 Hz，两路约各 305.5 Hz，每路 31 个样本生成约 100 ms 一组快照；`power_monitor_get()` 按单节 4.2 V 锂电池电压估算电量。`ui_view_battery(-1)` 显示未知 `?`，传入 0–100 时按百分比填充；无校准、饱和、初始化失败或过期均恢复未知。该内部绘制接口须持有 LVGL 锁。采样与估算见 [adc_measure](../../drivers/adc_measure/README.md) 和 [power_monitor](../power_monitor/README.md)。

## 文件和调度

### 按键功能入口

调用链：`hc165.c:scan_inputs()` → `hc165_keys_update()` 识别并累计事件 → `ui.c:ui_task()` 每 50 ms 调用 `hc165_take_events()` → `handle_keys()` 执行具体功能。

修改按键业务从 `ui.c` 的 `handle_keys()` 入手：HOME 的 KEY1/3 滚动功能列表或调整焦点目标，INFO/SETUP 的 KEY1/3 翻页或调用 `settings_set()` 和 `lcd_st7789_set_brightness()`；KEY2 短按执行/进入编辑/完成编辑，SETUP 长按调用 `settings_commit()`。`ui_key_hints.c` 只显示当前按键功能，不处理输入事件，也不执行保存。后续扩展仍由这一处统一消费并分发事件。

`app/focus_distance/focus_distance_get()` 是独立的对焦物距获取接口。FocusUnit 目前只有编码器计数，主控通信和“位置计数 → 物距”的标定尚未接入，因此该函数暂用本次 SDM50 快照，并设置 `using_actual=true`，占位标志仅保留在接口返回值中，屏幕不显示状态行。实测有效时两项数值和两个指针对齐；NO_TARGET 按用户约定将两项显示为 INF、两个指针指向 INF。实测太近时右值 NEAR、下指针停在零端点；对焦接口不增加 NEAR 状态，左侧占位值暂不可用、上指针隐藏。后续接入真实 FocusUnit 后，左值与上指针独立于实测 NEAR 状态。HOME 的 FOCUS 调参态目前只覆盖 UI 内部 `focus_target_mm`，尚未调用 FocusUnit 位置接口；该占位值以 50 mm 步进、范围 50–20000 mm。

比例尺刻度为 0、1、2、5、10、20 m 和 `INF`（无穷远）。为包含零点，有限距离采用 `x = 14 + 98 × ln(1 + d/1m) / ln(21)`；20 m 位于 x=112，INF 独立位于 x=139，中间断线分隔。20～49.999 m 仍显示真实数值、指针停在 20 m；合法返回值 <50 mm 显示 NEAR，≥50000 mm 的 NO_TARGET 显示 INF。50000 是“测不到”协议值，显示 INF 是约定，不代表确实测得无穷远，也无法排除太近或反射不足。等待、过期、停止或接收错误显示短横线、隐藏对应指针，不沿用 INF。

`ui_view.c` 只创建与更新 LVGL 控件；`ui.c` 负责快照、按键和参数保存。独立优先级 3、4096 字节栈任务，每轮处理事件和快照后阻塞 50 ms，不补跑过期周期，操作 LVGL 时持有官方移植锁。只更新当前页控件；文本、字体模式和编辑颜色按变化更新，电池和页面重复值跳过，避免相同样式也触发重绘。EEPROM 保存前释放显示锁；保存期间 UI 任务暂停取样，LVGL 官方任务仍可刷新。

曲线按单调时钟 100 ms 网格保存 101 点。调度延迟或 EEPROM 保存跨过的网格填空缺，不将同一个样本复制填满历史；只将 VALID 快照写入最新点。NEAR、INF、过期、停止和接收错误在曲线中均为 `LV_CHART_POINT_NONE`，不画成 0 m 或 50 m。横轴 10 s，纵轴单位 m、整数米边界；原始数据保留 mm。大字仅简化为近距一位小数、远距整数米；曲线、指针和对焦目标仍使用原始毫米值，50 mm 调参步进不变。显示位数不代表传感器精度。

`display_init()` 负责 CASE 7、完整 RAM 清屏和可见窗口偏移；`ui_start()` 建界面并开启约 300 ms 的背光渐亮。日常刷新由官方 LVGL 定时器管理，不调用屏幕测试的全屏刷新循环。`lcd_test` 源码仍保留，需要排查屏幕时可手动切换启动入口，两者不能同时运行。

主程序每 1 s 打印距离及 ADC/电源快照。本轮已修改源码、`sdkconfig`（打开 Montserrat 8/10/12 内置字体）及文档；按用户要求未编译、未测试、未烧录，实机未验证。
