# 电池充电状态

2026-10-20。TP4057 的 CHG / STB 经 R38 / R37 上拉到主控 +3.3 V，分别接 74HC165 的 D6 / D7，低电平有效。GPIO21 为 USB 有效电源检测。`charge_status_update()` 由 UI 任务每轮调用，即使当前显示 INFO 或 SETUP，也持续观察信号；不新增任务或定时器。

| 状态 | 判定 | 图标 / INFO |
| --- | --- | --- |
| 普通电量 | USB 无效、CHG/STB 均高、ADC 电池有效 | 原电量填充 / 电压与估算百分比 |
| 充电中 | USB 有效、CHG 低且 STB 高，稳定至少 200 ms | 左侧 8×14 px 闪电＋当前估算电量静态填充 / CHG |
| 已充满 | USB 有效、CHG 高且 STB 低，连续稳定至少 4 s | 满格＋上移后的对勾 / FULL |
| 无电池 | USB 有效、STB 低，连接后至少 3 个 CHG 下降沿，最近连续 2 个周期为 0.4–2.5 s，距最后下降沿不超过 3 s | 灰色空框＋斜杠 / NO BATTERY |
| 待确认 | USB 正在稳定、检测失败、外电有效时双高、双低未形成脉冲特征，或其它条件不足 | 橙色问号；有 ADC 电压时 INFO 显示电压 / ? |

USB 输入先稳定 200 ms。充满判定的 4 s 等待用于观察无电池周期脉冲；即使 UI 没采到脉冲低电平，HC165 保存的下降沿计数变化也会重置此等待，避免把脉冲间隙显示为充满。

HC165 的既有 5 ms 扫描同时保留 CHG 下降沿总数、最后时间和连续短周期计数；按键消抖、事件消费和扫描周期不变。显示状态的稳定判断在 UI 层进行，不从 CHG 瞬时低电平直接推断充电，也不把双高当作无电池。

依据为原理图链接的 [TP4057 原厂手册，第 7 页](https://www.toppwr.com/uploadfile/file/20230304/640302a47b738.pdf#page=7)：未接电池时 CHG 输出周期脉冲，BAT 外接 10 µF 时周期约 0.5–2 s。板上 C17=1 µF、C30=10 µF；软件的 0.4–2.5 s 容差、重复次数、STB 门槛和等待时间是本次选择的保守识别规则，并非手册保证的整板检测指标。BAT 端负载、实际电容和脉宽可能影响识别，条件不足时保留待确认，需实测后调整。

HOME 与独立 EJECT 页共用 `ui_battery.c/h`，主体均为 19×10 px，HOME 位于 (143,11)，EJECT 位于 (131,11)。2026-11-02 取消充电填充动画，普通和充电状态均按当前估算百分比静态填充；左侧闪电由 4×10 px 放大到 8×14 px，距主体 2 px，不显示百分比数字。充电但电量无效时保留闪电、隐藏填充并显示问号，避免把未知电量当作 0%；问号使用 14 px 字体。满格对勾和无电池斜杠保留，INFO 状态及 ADC / 电量换算不变。仅填充宽度或状态改变时更新，无动画时基、GIF 或整屏图像。未编译、测试或烧录，状态识别和实屏效果待验证。
