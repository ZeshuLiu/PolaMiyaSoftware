# 74HC165 按键驱动

对应 PM_Controller Rev2.0 的 U6。`hc165_init()` 已加入 `app_main()`，只在启动时调用一次。后台扫描任务独占 SPI3 和 GPIO39、GPIO40、GPIO41，不占用屏幕的 SPI2。

## 接线与时序

| 信号 | GPIO / 输入位 | 含义 |
| --- | --- | --- |
| /PL | GPIO39 | 拉低装载并行输入；不是普通 SPI 片选 |
| CP | GPIO40 | 空闲高电平，下降后读取 Q7，上升沿移位 |
| Q7 | GPIO41 | 依次输出 D7 至 D0；返回字节的 bit0 对应 D0 |
| KEY1–KEY6 | D0–D5 / bit0–bit5 | 低电平按下，板上已有上拉 |
| CHG | D6 / bit6 | 低电平表示充电状态有效 |
| STB | D7 / bit7 | 低电平表示充满状态有效 |

使用 ESP-IDF 官方 SPI Master 驱动，SPI3、Mode 2、500 kHz、MSB first，每次接收 8 bit。MOSI 与硬件 CS 均禁用，使用 `SPI_DMA_CH_AUTO` 启用 DMA；接收缓冲为 `DMA_ATTR` 修饰的静态 4 字节数组，位于内部 RAM 且按 4 字节对齐，实际传输长度仍为 8 bit。使用 `spi_device_polling_transmit()` 同步等待 DMA 传输完成后读取第一个字节。初始化采样与后台扫描依次使用该缓冲，不并发访问。DMA 负责数据搬运，CPU 仍轮询等待完成；单字节读取不以性能提升为目标。FreeRTOS tick 为 1 kHz，扫描目标周期 5 ms（5 ticks），实际唤醒仍受任务调度影响。按键消抖为 20 ms，长按阈值为 1000 ms，计时使用 `esp_timer_get_time()`，不依赖扫描次数。

GPIO、SPI 初始化、任务创建和 SPI 传输保留错误检查；/PL 电平操作不逐次检查。SPI 传输前回调在模式配置完成后拉低 /PL 1 µs，再拉高等待 1 µs，然后由硬件输出 8 个时钟。这样首次配置时钟电平发生变化也不会丢失 D7。回调随轮询传输在调用任务中执行，初始化采样完成后由扫描任务独占接口；按键事件规则不变。

器件装载和移位时序依据 [74HC165 数据手册](https://assets.nexperia.com/documents/data-sheet/74HC_HCT165.pdf)。

## 事件规则

| 场景 | 标志位 |
| --- | --- |
| 按下、松开均通过消抖，持续不足 1000 ms | 松开时置该键的短按位 |
| 持续按住达到 1000 ms | 置一次该键的长按位 |
| 已触发长按后继续保持或松开 | 不重复置长按位，不置短按位 |
| 松开候选边沿出现在 1000 ms 前，随后通过消抖 | 按候选松开时刻判定短按，消抖等待不计入按住时长 |
| 多个按键同时操作 | 各键独立识别，可同时置多个位 |
| 启动时已经按住 | 仅记录按下状态；松开后才开始接受该键的新事件 |
| 外部尚未清除事件 | 标志保持；同一类事件的同一位重复触发会合并，不计次数 |

只有 KEY1–KEY6 产生按键事件，CHG/STB 不参与长短按识别。BOOT 和 ESP_EN 不在此驱动范围内。时间判定以扫描到的边沿为准，有一个扫描周期以内的采样误差。

## 外部读取

| 接口 | 返回内容 | 是否清除事件 |
| --- | --- | --- |
| `hc165_get_inputs()` | 原始 8 位电平、消抖后的按下掩码、当前 CHG/STB 状态 | 否 |
| `hc165_get_events()` | `short_press` 和 `long_press` 两组掩码 | 否 |
| `hc165_take_events()` | 读取并清除当前两组掩码 | 是，读取和清除在同一临界区完成 |

接口在 `hc165_init()` 完成后由任务调用，不用于 ISR。由一个业务消费者调用 `hc165_take_events()`；监视任务可以调用 `hc165_get_events()`。驱动用临界区保护状态发布及事件读取，避免扫描任务置位时被外部清除覆盖。

```c
#include "hc165.h"

hc165_key_events_t events = hc165_take_events();
if (events.short_press & HC165_KEY1) {
    /* KEY1 短按 */
}
if (events.long_press & HC165_KEY1) {
    /* KEY1 长按 */
}

hc165_inputs_t inputs = hc165_get_inputs();
bool key2_is_pressed = (inputs.pressed & HC165_KEY2) != 0;
bool charging = inputs.charging;
```

`raw` 和 CHG/STB 为最新采样状态，未做充电状态消抖或组合判定。当前驱动提供标志位接口，尚未注册 LVGL 输入设备。
