# 吐片电机

U5 为 DRV8251A，接线取自 `main/PIN.h`：GPIO1 → IN1，GPIO2 → IN2。

- `film_motor_init()` 在屏幕初始化前调用，初始化到 IN1=IN2=1 制动状态；错误由启动入口处理。
- `film_motor_set_running(true)` 采用暂定方向：GPIO1 反向 PWM、GPIO2 恒为 1。LEDC 低速 Timer 1 / Channel 1，20 kHz、10 bit；不占用背光的 Timer 0 / Channel 0。
- `FILM_MOTOR_IN1_HIGH_PERCENT=0` 表示用户指定的 GPIO1 实际高电平占比：运行终点 IN1 恒低、IN2 恒高，即全驱动。代码换算为反相 LEDC 内部占空比 1024/1024；停止终点内部占空比为 0，物理 IN1 恒高。输入低电平驱动、高电平制动，不再用驱动占比命名这个参数。
- 启动与停止均使用 LEDC 硬件渐变，目标时长 `FILM_MOTOR_RAMP_MS=1000` ms。启动从当前占空比升到运行目标，停止渐变至驱动占空比 0，结束后 IN1=IN2=1 制动。
- 斜坡中再次切换启停时，先冻结当前占空比，再从该值开始新的 1 s 斜坡，不跳变到起点。渐变时间存在硬件步进量化误差，实际波形未测量。
- 渐变服务由现有屏幕初始化统一安装；电机仅使用自己的 Timer 1 / Channel 1，不重复安装或卸载共享渐变服务。
- 接口用于任务上下文。UI 为当前唯一运行命令调用者；驱动不操作 UI、不等待电机运行完成。
- 启停日志记录冻结渐变后的内部占空比、目标值和 PWM 频率。完整启动应记录 `0/1024 -> 1024/1024`；启动超过 1 s 后停止，应记录 `1024/1024 -> 0/1024`。这是 LEDC 寄存器读数，不是 GPIO 波形或轴转速测量。

2026-10-19 用户实机确认：启动先猛转、随后维持约半速的问题来自驱动芯片限流，解除电流限制后运行正常；保留现有启停斜坡及诊断日志。解除限流的具体硬件操作、当前限流阈值及电流采样是否仍有效未提供，不据此修改 BOM、网表或电流换算。尚无 GPIO1 波形和斜坡时长的量化测量；本轮未代为编译、测试或烧录。

HOME 功能顺序为 SETTINGS → FOCUS → EJECT → INFO。EJECT 处按 KEY2 启动斜坡并进入独立吐片页；再短按 KEY2 开始停止斜坡，约 1 s 后制动并返回 HOME。吐片页绿色亮度按目标斜坡时长从 20% 升至 100%，停止从当前亮度降至 20%；上下键无操作且导航箭头隐藏。中途再次按中键可反向切换，硬件斜坡不阻塞 UI。

电机驱动只做手动启停，不读取 GPIO6/7。FILM_KEY 锁存已由独立的 film_reload 低优先级任务处理：检测约 10 s 后恢复锁存，成功后把相纸余量设为 8 并保存 EEPROM。UI 按首次启动到最终停止斜坡目标结束严格超过 5 s 的规则，在吐片完成时扣 1 张并保存，最低 0；中途反向切换仍算同一次。电机驱动自身只控制硬件斜坡，不自动停机、不统计数量或累计时长、不写 EEPROM。用户已确认解除驱动限流后运行正常；实际方向、负载转速与停止效果未提供量化验收记录。

输入真值及驱动 / 制动 PWM 方式依据 [TI DRV8251A 数据手册，8.4.1 Bridge Control](https://www.ti.com/lit/ds/symlink/drv8251a.pdf)。
