# SDM50 激光测距

UART1：GPIO4 TX 经 R49=499 Ω 接 U9.2，GPIO5 RX 接 U9.3；U9.1 为 3.3 V，U9.4 为 GND。模块端 1=GND、2=VCC、3=RX、4=TX，线束不能按相同编号直连。

协议依据 [SDM50 手册](../../../docs/SDM50系列%20激光测距模块%20说明书.pdf)。默认 460800 baud、8N1、无流控，保持模块默认 500 Hz；手册未提供频率修改指令。

## 接收与更新

- 使用 ESP-IDF 6.1 官方 UHCI，将 UART1 接入 GDMA，收发均走 DMA。独占 UART1 和一个 UHCI 控制器，不安装普通 UART 接收驱动。
- 64 字节静态内部 DMA 缓冲，禁用 burst；UART 空闲阈值设为 4 个字符时间，并启用空闲 EOF 和 64 字节长度 EOF。
- DMA ISR 回调直接解析字节、校验和更新距离快照。不在 ISR 打印日志、调用 UI 或执行对焦业务。
- 本机 SDK 的 `uhci_receive()` 是单次接收；EOF 后停止 DMA。回调通知与中断同核的优先级 12 任务重新挂载缓冲；任务不解析或搬运距离数据。异常 EOF 清除半帧并重新接收，重新挂载失败则保留 RX_ERROR 并挂起接收任务，需重启恢复。
- 回调返回后才复用 DMA 缓冲，不保存回调数据指针。正常半帧跨接收保留，校验失败逐字节重新同步，兼容测距与命令应答交错。
- 这种方式仍存在 EOF 到任务重新挂载的间隙，不承诺连续无丢帧；长时间屏蔽中断或 Flash cache 暂停可能丢数据。当前不支持 cache 关闭期间完整 ISR 执行，不修改 sdkconfig。

测距帧为 `5C low high checksum`，距离单位 mm、小端编码，校验为负载字节求和取反。50～49999 mm 标为 VALID，50000（手册定义的测不到）及量程外值标为 NO_TARGET。非法校验不更新距离和时间戳。

## 接口

所有公开接口用于任务上下文；初始化在开机调用一次，不提供运行中销毁接口。`sdm50_init()` 成功只表示主控资源就绪，不表示模块在线。

| 接口 | 行为 |
| --- | --- |
| `sdm50_init()` | 配置 UART1、创建 UHCI 和重新挂载任务，启动 DMA 接收 |
| `sdm50_start()` | DMA 发送 `5A 0A 02 02 00 F1`，等待开启应答 |
| `sdm50_stop()` | DMA 发送 `5A 0A 02 00 00 F3`，等待停止应答；不切断模块电源 |
| `sdm50_get_sample(&sample)` | 临界区复制一致快照，不等待下一帧、不读取 UART FIFO |

启停命令通过互斥锁串行化，锁等待、前次 DMA 发送完成等待、应答等待各最多 200 ms，整次调用可能接近 600 ms。发送缓冲静态保留；即使前次等待超时，也必须等 DMA 完成后才覆盖。返回 ESP_OK 表示收到相应模式的合法应答；超时不证明模块没有执行命令，不自动重发。协议无事务序号，延迟到达的同模式应答不能与新命令严格区分。

结果包含距离、状态、时间戳、序号、校验错误计数和 DMA 接收错误计数。序号统计所有合法测距帧，包括无目标。仅 VALID 状态可用于对焦；读取时若超过 100 ms 无合法测距帧，则输出 STALE。STOPPED 与 RX_ERROR 不被超时状态覆盖。启停应答和后续测距帧均反映实际接收事件；继续收到测距帧会更新状态，不仅凭已发送命令判断停止成功。

```c
sdm50_sample_t sample;
if (sdm50_get_sample(&sample) == ESP_OK && sample.status == SDM50_VALID) {
    /* sample.distance_mm 是原始测距值，滤波和对焦映射由业务层处理。 */
}
```

主程序初始化后发送一次开启命令；失败记录警告并继续其它模块启动。未接入 UI、电机或滤波，没有自动重新连接、修改波特率或切换 I²C。
