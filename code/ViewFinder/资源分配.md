# ViewFinder 资源分配

本表对应 ViewFinder Rev 1.1、CH32V205CCT6 和当前固件。为传感器预留的引脚已在板级初始化中配置；外设或中断是否启用以各表的状态为准。

## DMA

| 控制器 / 通道 | 请求源 | 用途 | 模式与完成处理 |
| --- | --- | --- | --- |
| DMA1 通道 2 | USART3 TX | UART2 向 SDM50 发送启动命令 | 单次传输，TC / TE 中断结束本次发送 |
| DMA1 通道 3 | USART3 RX | UART2 接收 SDM50 数据 | 64 B 循环缓冲，HT / TC / TE 中断；USART3 IDLE 时也读取新数据 |
| DMA2 通道 7 | SPI1 TX | ST7735 距离图条带和 ACT 文字发送 | 单次传输，TC / TE 中断；两块 5,220 B 缓冲交替使用 |

SPI1 TX 默认请求映射到 DMA1 通道 3，与 USART3 RX 冲突。LCD 驱动设置 `DMA_RemapCH_SPI1` 后，SPI1 TX 改走 DMA2 通道 7，SPI1 RX 的映射也随之改到 DMA2 通道 6。当前 LCD 只写；后续启用 SPI1 RX DMA 时按重映射后的通道配置。DMA1 通道 1、4～8 和 DMA2 通道 1～6 当前未分配，新增用途时仍需核对芯片的请求映射。 [CH32V205 应用手册，第 11 章及 DMA_SPI1_RM](https://ch32-riscv-ug.github.io/CH32V205/datasheet_zh/CH32V205RM.PDF)

## 中断

| PFIC 向量 | 优先级 | 来源或作用 | 状态 |
| --- | ---: | --- | --- |
| `USART3_IRQn` | 0 | SDM50 接收线路空闲（IDLE）及接收错误（ERR） | 已启用 |
| `DMA1_Channel2_IRQn` | 0 | SDM50 发送完成（TC）或 DMA 传输错误（TE） | 已启用 |
| `DMA1_Channel3_IRQn` | 0 | SDM50 接收半满（HT）、回卷（TC）或 DMA 传输错误（TE） | 已启用 |
| `USART4_IRQn` | 0 | 板上 UART1 RX，探测请求逐字节接收（RXNE） | 已启用 |
| `USART5_IRQn` | 0 | 板上 UART1 TX，应答和测距转发（TXE） | 有待发数据时启用 TXE |
| `EXTI4_IRQn` | 0 | PB4 / INT1，LSM6DS3TR-C 陀螺仪数据就绪，上升沿 | 传感器初始化成功后启用 |
| `EXTI9_5_IRQn` | 0 | PB8 / EXTI8，OPT4001 转换完成，下降沿 | 传感器初始化成功后启用 |
| `I2C1_EV_IRQn` / `I2C1_ER_IRQn` | 0 | OPT4001 寄存器突发读取的事件和错误 | 读事务期间启用外设中断 |
| `SPI2_IRQn` | 0 | LSM6DS3TR-C 的 RXNE / ERR，推进 SPI 读取 | 读事务期间启用外设中断 |
| `DMA2_Channel7_IRQn` | 0 | LCD 发送完成（TC）或传输错误（TE） | 已启用 |
| `TIM2_IRQn` | 0 | 1 ms 系统事件，用于显示节拍和传输超时 | 已启用 |

USART3 和 DMA1 通道 3 的接收处理共用帧解析器，并向主控 UART1 的发送队列入队。保持这些中断与 USART4、USART5 同优先级，避免相互抢占。主循环读取最新距离时，短暂屏蔽 USART3 和 DMA1 通道 3 的中断。LCD 和两种传感器通过 `AppEvents` 标志把中断结果交给主循环，空闲时执行 WFI。上电绘制首帧时等待 LCD 完成后再打开背光，DMA 故障时回退到 SPI 轮询发送。

## 外设与定时器

| 资源 | 用途 | 状态 |
| --- | --- | --- |
| USART3 | 板上 UART2，SDM50 收发，460800 baud、8N1 | 已启用 |
| USART4 / USART5 | 板上 UART1，分别接收和发送，460800 baud、8N1 | 已启用 |
| SPI1 | ST7735 四线写入，当前 SCK 5 MHz | 已启用 |
| SPI2 | LSM6DS3TR-C，PB12 软件片选，四线 Mode 3，SCK 5 MHz | INT1 发起，SPI2 IRQ 完成读数 |
| I²C1 | OPT4001（0x44），PB6 / PB7，100 kHz | EXTI8 发起，I²C1 事件中断推进读取 |
| TIM2 | 1 ms 事件时基；距离图每 100 ms 调度一次 | 更新中断 |
| TIM3_CH3 | LCD 背光，PB0，低有效，约 2 kHz PWM | 已启用，无中断 |
| SysTick | `Delay_Us` / `Delay_Ms` 的计数 | 轮询，无中断 |
| TIM1、TIM4 | 可供后续功能使用 | 未分配 |

OPT4001 的采样率由 `OPT4001_SAMPLE_RATE_HZ` 配置，支持 5 / 10 / 20 / 40 Hz，默认 10 Hz。PB8 中断记录转换完成，I²C 事件中断读出结果，主循环执行校验。多次就绪通知积压时读取最新结果。

LSM6DS3TR-C 由 `LSM6DS3TRC_ODR_HZ` 设置陀螺仪与加速度计的输出速率，默认 26 Hz，支持 52 / 104 Hz。INT1 通知就绪，SPI2 中断读出两组数据状态及六轴数据，主循环解码。接口保留最近一组样本，高采样率或前台延迟时可能合并采样。

## 静态缓冲

| 缓冲 | 大小 | 用途 |
| --- | ---: | --- |
| `draw_pixels` | 10,440 B | 两块 LCD RGB565 条带缓冲，复用其中一块绘制文字 |
| `finder_distance_mm` | 2,178 B | 33×33 `uint16_t` 毫米距离表，SDM50 接收中断暂写中心 `[16][16]` |
| `rx_dma` | 64 B | SDM50 循环接收区 |
| `start_command` | 6 B | SDM50 启动命令，静态放在 SRAM 供 DMA 读取 |

距离表初始化为 `0xFFFE`（未采样）。`0x0000` 表示太近，`0xFFFF` 表示无目标或超量程。其余值以毫米存储，编码分辨率为 1 mm。
