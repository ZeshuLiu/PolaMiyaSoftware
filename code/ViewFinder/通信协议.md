# 主控器与取景器串口协议

协议版本：`0x01`。本文定义 PolaMiya 主控器与 ViewFinder Rev 1.1 之间的串口通信，以及主控直连 SDM50 时的兼容流程。

> 当前取景器固件已支持识别应答（0x01），测距暂按 SDM50 原始 5C 帧转发。两端接入 0x0F 后，再按本文格式封装测距上报。

## 串口配置

主控器使用原测距 UART。取景器使用板上 UART1，TX 为 PB2 / USART5，RX 为 PB1 / USART4。双方 TX 接对方 RX，共地。串口为 3.3 V 逻辑、460800 baud、8N1、无流控。

取景器通过板上 UART2（PB10 / PB11，USART3）与 SDM50 通信，负责启动连续测距及校验模块原始帧。

## 帧格式

```text
55 AA CMD LEN [DATA × LEN] CKS
```

帧中各字段均按字节传输。多字节整数使用小端序。

| 字段 | 字节数 | 含义 |
| --- | ---: | --- |
| `55 AA` | 2 | 固定帧头 |
| `CMD` | 1 | 消息类型 |
| `LEN` | 1 | `DATA` 的字节数，范围 0～255 |
| `DATA` | `LEN` | 载荷，`LEN=0` 时为空 |
| `CKS` | 1 | `CMD`、`LEN` 和所有 `DATA` 字节之和取低 8 位，再按位取反 |

校验时将 `CMD`、`LEN`、`DATA` 和 `CKS` 相加，低 8 位应为 `0xFF`。接收端按 `LEN` 确定帧边界，允许载荷包含 `55 AA`。校验失败或已知命令的长度错误时，丢弃候选帧的首字节并重新找帧头。校验通过但命令未知的帧按长度消费。

## 命令表

| CMD | 名称 | 方向 | LEN | DATA |
| --- | --- | --- | ---: | --- |
| `0x01` | 取景器识别应答 | 取景器 → 主控器 | 1 | 协议版本，当前为 `01` |
| `0x0F` | 测距上报 | 取景器 → 主控器 | 2 | `DIST_LO DIST_HI`，SDM50 原始距离值，单位 mm |

### 取景器识别应答（`0x01`）

主控器初始化后发送原有 SDM50 启动命令 `5A 0A 02 02 00 F1`。取景器把这串完整字节识别为探测请求，返回：

```text
55 AA 01 01 01 FC
```

应答表示取景器串口就绪，并报告协议版本。SDM50 的启动和测距由取景器独立处理，所以即使模块离线也要应答。首次应答排在测距上报之前。主控重发探测请求时，取景器再次应答即可。

### 测距上报（`0x0F`）

收到校验通过的 SDM50 测距帧后，取景器将原始距离值封装上报。主控沿用现有 SDM50 距离判定：

| 原始值 | 含义 |
| --- | --- |
| 0～49 mm | 过近 |
| 50～49,999 mm | 有效距离 |
| 50,000 及以上 | 无目标或超量程 |

例如，1234 mm（`0x04D2`）对应 `55 AA 0F 02 D2 04 18`。无目标值 50,000（`0xC350`）对应 `55 AA 0F 02 50 C3 DB`。

每条合法的 `0x0F` 更新主控的最新测距值和接收时间。超过 100 ms 没有合法测距帧时，沿用主控现有的过期判定。只有模块明确返回无目标值时才上报无目标。

## 主控上电识别与回退

1. 启用 UART 接收，发送 `5A 0A 02 02 00 F1`，开始识别。
2. 第一条合法的 SDM50 启动应答或 `5C` 测距帧确认直连 SDM50，后续使用原有协议。
3. 第一条合法的取景器 `0x01` 应答确认取景器已连接。版本受支持时切换到取景器协议，结束原 SDM50 应答等待，通过 `0x0F` 更新测距。收到不支持的取景器版本时报告版本不兼容。
4. 超时、半帧和校验错误都不足以确认模式。识别超时可重发探测请求。模式确认后，测距过期只影响测距状态。
