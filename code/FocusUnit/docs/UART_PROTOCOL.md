# FocusUnit UART 协议 v0.1

固件已按本协议实现指令收发，尚未编译或实机验证。调度器启动 700 ms 后自动沿 B 方向寻零；触底校验成功后将当前位置设为 -500 RAW，再自动定位到 0 RAW。零位有效后才能接受 RAW 定位。

## 1. 角色与串口参数

| 项目 | 约定 |
| --- | --- |
| 主机 | 发送指令，等待 FocusUnit 响应 |
| 设备 | FocusUnit 接收并处理主机请求，发送对应响应；不主动推送 |
| 串口 | USART1，460800 baud，8N1 |
| 引脚 | PA2 TX、PA3 RX（均相对 FocusUnit） |
| 收发 | USART 中断收发；RX DMA1_CH3、TX DMA1_CH2 已预配置但未使用 |

## 2. 公共帧格式

所有多字节整数采用小端序；有符号整数采用二进制补码。以下偏移相对**帧起始**，从 0 开始。

| 帧偏移 | 字段 | 类型 / 字节数 | 内容 |
| ---: | --- | --- | --- |
| 0 | SOF | 2 字节 | `A5 5A` |
| 2 | VERSION | u8 / 1 | `0x01` |
| 3 | TYPE | u8 / 1 | 主机请求 `0x00`；设备响应 `0x01`，设备只处理请求 |
| 4 | SEQ | u8 / 1 | 请求序号；响应复制请求 SEQ |
| 5 | CMD | u8 / 1 | 命令编号；响应复制请求 CMD |
| 6 | LEN | u8 / 1 | payload 字节数，范围 0～64 |
| 7 | payload | LEN 字节 | 请求参数或响应数据 |
| 7 + LEN | CRC | u16 / 2 | CRC 小端存放 |

帧总长为 `9 + LEN` 字节。CRC 为 CRC-16/CCITT-FALSE：多项式 `0x1021`、初值 `0xFFFF`、输入输出不反射、输出异或 `0x0000`；计算范围从 VERSION 至 payload 末字节，不含 SOF 和 CRC。

## 3. 主机指令

下列请求参数偏移均相对**请求 payload 起始**，从 0 开始；CMD 均为十六进制。请求长度不符返回 BAD_LENGTH，参数越界或未列值返回 BAD_PARAM；拒绝不改变运动。

| CMD | 指令 | 请求 LEN | 作用 |
| --- | --- | ---: | --- |
| `0x01` | 状态查询 | 0 | 查询工作、位置和运动状态 |
| `0x02` | ADC 查询 | 0 | 查询当前可用的 ADC 帧 |
| `0x10` | Stop | 0 | 双高制动 |
| `0x11` | Glide | 2 | 指定方向运动，选择普通 Glide 或完整寻零 |
| `0x12` | OpenLoop | 3 | 指定方向及占空比开环驱动 |
| `0x13` | MoveRaw | 4 | 移动到指定 RAW 位置 |

状态查询、ADC 查询及 Stop 的请求 payload 为空，LEN 均为 0。

**Glide（`0x11`）**

| payload 偏移 | 字段 | 类型 / 字节数 | 取值 |
| ---: | --- | --- | --- |
| 0 | direction | u8 / 1 | 0：A；1：B |
| 1 | seek_zero | u8 / 1 | 0：普通 Glide，触底制动但不置零；1：完整寻零 |

**OpenLoop（`0x12`）**

| payload 偏移 | 字段 | 类型 / 字节数 | 取值 |
| ---: | --- | --- | --- |
| 0 | direction | u8 / 1 | 0：A；1：B |
| 1 | duty | u16 / 2 | 0～1000 千分比；0 为制动 |

**MoveRaw（`0x13`）**

| payload 偏移 | 字段 | 类型 / 字节数 | 取值 |
| ---: | --- | --- | --- |
| 0 | target_raw | i32 / 4 | 相对当前零点的软件累计四倍频位置 |

| 指令 | INITIALIZING | NORMAL | ERROR |
| --- | --- | --- | --- |
| 状态 / ADC 查询 | BUSY | 零位有效时可查询，否则 BUSY | 零位无效时 BUSY |
| Stop / Glide / OpenLoop | BUSY | 零位有效时可受理，否则 BUSY | 零位无效时 BUSY |
| MoveRaw | BUSY | 零位有效时可受理，否则 BUSY | 零位无效时 BUSY |

零位尚未确认时，所有合法请求均返回 BUSY，包括状态、ADC 和 Stop；因此 Stop 不能中止寻零，也不是急停命令。寻零失败时零位仍无效，串口请求也返回 BUSY；故障可通过 SWD 查看。
这段时间的 BUSY 响应不写入去重缓存，零位确认后可重发请求。

请求示例（十六进制，包含 CRC；可用于手动重新寻零）：

1. 沿 B 方向完整寻零，SEQ=1：`A5 5A 01 00 01 11 02 01 01 9D C3`。
2. 使用新的 SEQ 查询状态，确认 `work_state=1` 且 `zero_valid=1`：`A5 5A 01 00 02 01 00 0C E6`。
3. 定位到 +2000 RAW，SEQ=3：`A5 5A 01 00 03 13 04 D0 07 00 00 22 5B`。

寻零响应为受理结果，实际完成须通过状态查询确认。后续查询使用新 SEQ。

## 4. FocusUnit 设备响应

所有响应 payload 的第 0 字节为 RESULT。控制指令成功响应仅有此字节；ACCEPTED 表示受理并执行命令入口，**不表示运动完成**。

| RESULT | 名称 | 含义 |
| --- | --- | --- |
| `0x00` | ACCEPTED / 查询成功 | 控制已受理，或查询数据有效返回 |
| `0x01` | BAD_LENGTH | 合法帧的命令 payload 长度错误 |
| `0x02` | BAD_PARAM | 命令参数无效 |
| `0x03` | BUSY | 初始化中或尚未就绪 |
| `0x04` | ERROR | 故障锁存 |
| `0x05` | NO_DATA | ADC 当前没有可用帧 |
| `0x06` | SEQ_CONFLICT | SEQ 与缓存相同但请求内容不同 |
| `0x07` | UNKNOWN_CMD | 未定义的 CMD |

| CMD | 成功响应 LEN | 成功 payload | 失败响应 LEN |
| --- | ---: | --- | ---: |
| `0x01` | 24 | RESULT + 状态字段 | 1 |
| `0x02` | 24 | RESULT + ADC 字段 | 1 |
| `0x10`、`0x11`、`0x12`、`0x13` | 1 | RESULT | 1 |
| 未定义 CMD | — | — | 1 |

失败响应只含 RESULT。以下偏移均相对**响应 payload 起始**，从 0 开始，LEN 包含 RESULT。

### 状态查询成功响应（`0x01`，LEN=24）

| payload 偏移 | 字段 | 类型 / 字节数 | 含义 |
| ---: | --- | --- | --- |
| 0 | RESULT | u8 / 1 | `0x00` |
| 1 | work_state | u8 / 1 | 工作状态，见下表 |
| 2 | mode | u8 / 1 | 电机模式，见下表 |
| 3 | direction | u8 / 1 | 0：A；1：B |
| 4 | duty | u16 / 2 | 已发布的输出占空比，千分比 |
| 6 | initialized | u8 / 1 | PWM 初始化状态 |
| 7 | zero_valid | u8 / 1 | 零位是否有效 |
| 8 | seek_zero | u8 / 1 | 是否正在执行完整寻零 |
| 9 | home_attempts | u8 / 1 | 寻零触底次数 |
| 10 | home_error_counts | i32 / 4 | 最近一次寻零触底清零前位置 |
| 14 | position | i32 / 4 | 当前软件累计四倍频位置 |
| 18 | target_raw | i32 / 4 | 最近一次受理的定位目标 |
| 22 | move_state | u8 / 1 | 最近一次定位状态，见下表 |
| 23 | glide_completed | u8 / 1 | 普通 Glide 停止或寻零刚成功；自动定位启动后清零 |

| 字段 | 数值及含义 |
| --- | --- |
| work_state | 0 INITIALIZING；1 NORMAL；2 ERROR |
| mode | 0 STOP；1 GLIDE；2 OPEN_LOOP；3 ERROR；4 MOVE_RAW |
| move_state | 0 IDLE；1 MOVING；2 REACHED；3 STALLED；4 CANCELED |
| initialized、zero_valid、seek_zero、glide_completed | 0 否；1 是 |

状态来自主循环的电机及编码器快照，并非硬件同步采样。定位到位后继续监测，超出允差时恢复修正；其他控制命令可以取消定位。

### ADC 查询成功响应（`0x02`，LEN=24）

| payload 偏移 | 字段 | 类型 / 字节数 | 含义 |
| ---: | --- | --- | --- |
| 0 | RESULT | u8 / 1 | `0x00` |
| 1 | timestamp_ms | u32 / 4 | 本帧请求时刻，调度时基 ms |
| 5 | sequence | u32 / 4 | ADC 扫描序号 |
| 9 | valid | u8 / 1 | VREFINT 可用于换算时为 1，否则为 0 |
| 10 | raw_ntc1 | u16 / 2 | NTC1 原始 ADC 计数 |
| 12 | raw_3v3 | u16 / 2 | 3V3 采样原始 ADC 计数 |
| 14 | raw_ntc2 | u16 / 2 | NTC2 原始 ADC 计数 |
| 16 | raw_6v | u16 / 2 | 6V 采样原始 ADC 计数 |
| 18 | raw_motor | u16 / 2 | 电机电流采样原始 ADC 计数 |
| 20 | raw_temperature | u16 / 2 | MCU 温度传感器原始 ADC 计数 |
| 22 | raw_vrefint | u16 / 2 | 内部参考电压原始 ADC 计数 |

返回最近一次发布且当前可用的帧；新一轮扫描期间可能返回 NO_DATA。valid 不代表机械状态。

## 5. 交互与异常处理

| 情况 | 处理 |
| --- | --- |
| 正常请求 | 主机一次只允许一个未完成响应的请求；每个新请求的 SEQ 递增并自然回绕 |
| 响应等待超时 | 等待时间暂定 100 ms；只重发相同帧，避免重复执行。时间待串口实测 |
| 同 SEQ、同 CMD 和 payload | 设备重发最近一次缓存的完整响应，不重复执行；查询也会得到旧缓存 |
| 查询运动进展 | 使用新 SEQ 发起新查询 |
| 同 SEQ、不同 CMD 或 payload | 返回 SEQ_CONFLICT，不改变缓存 |
| 不同 SEQ | 执行请求并替换最近一次请求和响应缓存 |
| 设备复位 | 缓存丢失；主机重新查询状态，不能假设此前命令是否执行 |
| 帧格式、版本、类型、CRC 错误或 LEN 超出范围 | 丢弃帧，不响应、不执行；从后续 SOF 重新同步 |
| 合法帧但命令长度或参数错误 | 返回 BAD_LENGTH 或 BAD_PARAM，不改变运动 |
| 部分帧接收时两字节间空闲达到 20 ms | 丢弃部分帧，从后续 SOF 重新同步；20 ms 暂定，待串口实测 |
| SEQ 冲突或持续无响应 | 由主机处理；不能无条件更换 SEQ 重发运动命令 |

## 6. 运动行为与实现边界

| 项目 | 约定及待验证内容 |
| --- | --- |
| RAW | 相对当前零点的 int32 软件累计四倍频位置，不是 TIM3 16 位计数器或 ADC 值；32 位回绕时不按最短路径定位 |
| 定位方向 | 编码器位置增加必须对应电机正方向；默认 A 和编码器符号 +1 的物理对应关系尚未实测 |
| 定位到位 | 目标误差在 ±50 计数内制动，持续 1 s 后标记 REACHED；超出允差时重新修正 |
| 定位占空比 | 按误差方向以 800‰ 驱动，实机效果待验证 |
| 定位堵转 | 驱动后连续 3 个新 ADC 完整帧 `raw_motor > 2000` 时制动并标记 STALLED，不置零 |
| 控制切换 | Stop、Glide、OpenLoop 取消定位；新的 MoveRaw 替换目标 |
| OpenLoop 输出 | 从定位切换时先制动；其他开环更新保留原输出直到下一电机任务，随后应用并发布新命令 |
| 限制 | 暂无行程限制或定位超时；寻零故障锁存及上电恢复沿用现有固件 |

协议不定义故障清除、启动加载器、固件升级、认证或数据推送。方向、串口负载、定位参数、过冲、堵转和容量均待实机验证。电机、编码器、ADC 接口由主循环调用；UART 回调只缓存字节或收发状态。ADC 快照不可用时返回 NO_DATA。定位期间禁止 SWD 置零和正方向变更；调用者不得直接修改编码器符号、低层置零或配置结构体。
